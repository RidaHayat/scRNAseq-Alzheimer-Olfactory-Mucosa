# Local input data

The analysis needs two standard 10x Genomics folders named `AD1` and `Control2`. Each folder should contain `matrix.mtx`, `barcodes.tsv`, and `genes.tsv` (or `features.tsv`). Put them under this directory, or set the `DATA_DIR` environment variable to the parent folder containing both samples.

The source accession and sample-level metadata were not supplied with this project, so they are not inferred here. Keep count matrices, archives, and participant-level files out of this public repository. Confirm the original data source and its access terms before sharing derived data.
